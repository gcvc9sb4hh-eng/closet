# マイクローゼット

服や持ち物を管理するスマホ向けWebアプリ（PWA）。

- 写真・カテゴリ・色・ブランド・シーズン・価格・収納場所を登録
- 「今日着た」で着用回数を記録、分析タブで手放し候補を表示
- データはすべて端末のブラウザ内（IndexedDB）に保存され、サーバーには送られません
- 購入履歴（ユニクロ・GU・Amazon・楽天など）のスクショからまとめて登録
  - 無料：アプリがコピーする指示と一緒にスクショをAIアプリ（Claude・ChatGPTなど）に送り、答えを貼り付ける
  - 任意：Claude APIキーを設定すると、スクショを選ぶだけで自動読み取り（APIキーは各端末の localStorage にのみ保存）
- 服の写真から1枚＝1アイテムでまとめて登録
- JSON / CSV でバックアップ可能

ビルド不要。`index.html` を静的ホスティングするだけで動きます。
